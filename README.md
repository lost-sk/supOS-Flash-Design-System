# supOS Flash 设计规范

版本 0.1 草案｜面向产品官网、AI 工作台及传播物料。品牌蓝取自提供的 supOS Logo，使用前结合实际产品与品牌要求评审。

- [品牌基础](01-品牌基础.md) — 标识、色彩和字体。
- [官网与产品工作台](02-官网与工作台.md) — 页面结构、交互与组件。
- [传播物料](03-传播物料.md) — 海报、视频封面、视频。
- [执行与检查](04-执行与检查.md) — 设计流程、交付清单。

## 参考与优先级

[豆包工作](https://www.doubao.com/work)为首要参考，依据实际查看的官网首屏和页面内容，借鉴其居中价值主张、单一主行动按钮、大幅产品演示、按能力分章节的叙事方式。内部客户端细节未核实，工作台规范为设计建议。

[Tier0 Design System](https://github.com/FREEZONEX/Tier0-Design-System)为次要参考，借鉴共享基础、按场景拆分和规范入口的组织方式。品牌颜色依据本项目 Logo。

## 适用边界

文中数值和示例是首版设计提案，实际品牌色卡、字体授权、产品功能、平台适配和视觉样稿仍需确认。所有产品截图与事实应使用已核实素材。
