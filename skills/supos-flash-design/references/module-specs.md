# 设计期模块页规格（可选扩展）

仅在 `withDesign: true` 时生成。这些页面是 **supOS Flash 平台自身的设计期界面**，用于让客户看到「应用被配置进平台」的完整语境；它们不代表客户应用的功能，交付说明里必须写清这一点。

实现位于 [`../assets/l2/`](../assets/l2/)（模块定义）与 [`../assets/page/`](../assets/page/)（交互脚本），由生成器渲染。

## 菜单层级（线上实测）

```
首页
数据平台
  ├ 连接服务      数据源注册 · 数据接入服务
  ├ 建模服务      工厂模型 · 语义模型
  └ 存储服务      数据库资源管理 · SQL 联邦查询
AI 与工具         知识库 · 大模型网关 · Copilot · OpenAPI 开放
APP 管理          APP 运行管理 · APP 综合设计工具
Agent 管理
系统设置
  ├ 基础配置      ▸ 主题配置 / 菜单配置 / 数据字典 / 安全策略
  └ 企业运营配置  ▸ 组织管理 / 岗位与角色 / 用户与权限
应用商店
```

「工作流管理」按用户口径移除；「设计期」不是「设计器」。

## 模块页必备元素

| 页面 | 必须出现 |
| --- | --- |
| 数据源注册 | 四类统计卡 + 数据源表格（名称 / 类型 / 地址 / 状态 / 时间 / 操作）+ 新增向导；提示联邦查询只读、UNS 无事务 |
| 数据接入服务 | 采集点列表、协议、位号数、同步流程（历史保存 / 下写开关） |
| 工厂模型 | 左侧 UNS 命名空间树 + 右侧位号明细（实时值 / 质量）+ 模型统计 |
| 语义模型 | 模型 / 指标 / 关系 / 知识 四个 tab；标注「登记 / 检索 / 只读，≠ 规则求值器」 |
| 数据库资源管理 | 资源实例表 + 四类统计；区分 PostgreSQL / TimescaleDB / MinIO |
| SQL 联邦查询 | 只读 SQL 编辑器 + 结果表；显式提示 `READ_ONLY_VIOLATION` |
| 知识库 | 检索框、文档库（切片数 / 向量模型 / 状态）、带来源的检索结果 |
| 大模型网关 | 模型目录、供应商、配额、调用统计；标注是平台唯一模型出口 |
| Copilot | 用户输入 / 计划 / 执行回执三段；写操作走契约 + confirm + 回执 |
| OpenAPI 开放 | API 目录 / WebSocket·MQTT / 事件开放三个 tab |
| APP 运行管理 / 综合设计工具 | 已安装应用卡片 / 六类设计工具入口 |
| Agent 管理 | Agent 目录、runtimeType、callable、状态 |
| 基础配置 | 4 个子 tab；主题配置列出可换肤资源 |
| 企业运营配置 | 3 个子 tab；组织树 + 组织信息 / 角色表 / 用户表 |
| 应用商店 | 可安装应用卡片 + 安装 / 预览 |

首页为可调布局的分组卡片门户：常用（10 个真实图标快捷入口）、数据源管理、工厂模型、数据库资源管理、APP 综合设计工具、APP 运行管理。统计数字一律标注「示例 / 线上快照」。

## 交互能力

`window.FlashUI`（见 `assets/shell/interact.js`）提供：Toast、Modal、confirm、Drawer、Popconfirm、Dropdown、表单校验。16 个模块页已实现注册向导、表单校验、弹窗编辑、抽屉详情、删除确认、Agent 对话流等二级交互。

表单校验约定：字段容器 `.field` 内的控件带 `data-req` / `data-max` / `data-pattern` / `data-err` / `data-errMax`，失败时 `.field.has-error` 并把文案写进 `.f-err`。

## 不还原的部分

设计器画布（报表 / 工艺流程图 / 3D 数字孪生 / 桌面组态编辑器的内部工具界面）不还原——对应微前端包源码不在交付范围内，页面里以工具入口卡片代替，并标注边界。
