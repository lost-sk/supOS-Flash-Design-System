# 知识库问答智能体 · 简版 PRD

## 目标与入口

通过自然语言查询知识库、获取回答并查看参考资料。

平台入口：**知识库问答智能体 → 问答助手**，右侧打开聊天工作台。

## 核心需求

| 功能 | 要求 |
| --- | --- |
| 欢迎页 | 展示知识库主题图和大标题“知识库问答智能体”，不展示副标题 |
| 提问 | 非空内容可发送；Enter 发送，Shift + Enter 换行。发送按钮变蓝，悬停加深 |
| 检索范围 | 默认全部有权限的知识库；支持搜索、全选、多选及“全部 / 已选”筛选 |
| 范围面板 | 固定大小、列表内部滚动；底部显示数量、取消和确定。至少选择一个，确定后生效 |
| 范围记忆 | 当前会话沿用所选范围，新建对话恢复全部；每条问题记录当时的范围 |
| 历史会话 | 支持查看、搜索历史和新建对话 |
| 参考资料 | 回答上方显示“搜索 N 个关键词，参考 M 篇资料”；点击在原位展开关键词和蓝色编号资料列表，可收起 |
| 辅助操作 | 加号选择附件；切换闪速/深度思考；选择模型，列表不展示 Logo |

## 原型与交付

- `portal.html`：平台菜单入口；`index.html`：聊天工作台；`assets/`：图片和图标。
- 双击 `portal.html` 即可演示。
- 当前知识库、回答和参考资料均为 Mock，会话刷新后重置。
- 正式接入需实现知识库权限、检索与模型调用、会话保存及文件上传；引用内容与数量来自真实检索结果。

验收：入口可用、范围选择正确、问答与历史可演示、引用可原位展开，界面与确认的 HTML 原型一致。
