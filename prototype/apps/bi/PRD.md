# 数智BI智能体 · PRD

版本：V0.1｜日期：2026-11-04

## 1. 产品定位

基于数据洞察智能体精简的自然语言问数助手。用户选择数据来源后提问，获得结论、表格和图表，支持连续追问、查看取数过程，以及收藏和语义知识沉淀。

界面参照知识问答智能体；语义模型、指标口径与查询统一通过 Diviner，数智BI智能体 负责会话上下文和结果展示。

## 2. 核心流程

选择数据来源 → 输入问题 → 展示处理过程和查询结果 → 切换图表或查看取数过程 → 询问是否收藏并保存到语义模型 → 继续对话。

## 3. 功能要求

| 模块 | 要求 |
| --- | --- |
| 左侧栏 | 参照知识问答智能体，包含折叠、新对话、搜索对话、对话历史，底部为我的收藏 |
| 欢迎页 | 使用已确认的 数智BI智能体 欢迎图，保留示例问题；不显示顶部附加标题栏 |
| 数据来源 | 入口位于输入框底部、Enter 发送提示左侧；默认未选，显示提示并禁用发送；未选来源仍可查看历史对话；选好数据且问题非空后可发送 |
| 来源面板 | 三个图标入口：关联「工业元」建模、上传外部数据、分析偏好补充；点击切换内容 |
| 工业元建模 | 支持节点搜索、树形多选和父子勾选联动；取消不生效，确定后应用，至少选择一项 |
| 外部数据 | 支持 Excel/CSV；正式接入需完成文件解析及 Diviner 可查询模型登记 |
| 分析偏好 | 补充业务背景和展示要求，不计为数据来源，不覆盖权威指标口径 |
| 输入与模型 | Enter 发送，Shift + Enter 换行；模型菜单与圆形箭头发送按钮参照知识问答智能体 |
| 连续追问 | 沿用时间、指标、筛选条件和数据范围；本轮明确修改的条件优先，口径不明确时澄清 |
| 处理过程 | 按知识问答样式展示可展开的步骤摘要：识别范围、匹配模型、执行取数、整理结果 |
| 查询结果 | 展示结论、指标、来源、统计区间和耗时；同一结果集支持表格、柱状图、折线图、饼图切换，按数据适配可用类型 |
| 回答操作 | 复制、下载、收藏、更多；无分享和推荐追问。收藏位于下载右侧，悬停提示「收藏并添加到语义模型」 |
| 更多菜单 | 取数过程、删除；取数过程不设置重复入口 |
| 取数过程 | 居中弹窗，左侧步骤导航，右侧展示子问题、数据集和带语法高亮的实际 SQL，支持复制 |

## 4. 收藏与语义保存

每次回答后，助手在对话流中询问：**是否将本次对话内容收藏并保存到语义模型？**

- 提供「收藏并保存」「暂不保存」，也支持文字回复，不使用弹窗。
- 用户直接提出新问题时继续查询，不默认同意保存。
- 我的收藏以用户问题为主标题，结论为下方灰字；支持查看与取消收藏。
- 收藏与语义保存分别反馈结果。语义沉淀需对应 Diviner 支持的查询样例、术语、规则等对象，具体写入及审批方式待确认。

## 5. 验收重点

- 无数据来源不能发送；来源选择、模型切换、侧栏操作正常。
- 追问保留有效上下文；历史结果保留当时的数据范围和口径。
- 图表切换数据一致，处理摘要可收起，取数步骤与 SQL 对应真实执行。
- 收藏确认在对话流内完成；收藏列表的问题、结论和状态正确。
- 数据与语义操作受权限控制；无数据、无模型、查询失败和保存失败给出明确反馈。

## 6. 原型与交付

- `portal.html`：平台入口，参照知识库智能体 portal，嵌入同目录 `index.html`。
- `index.html`：当前正式原型。
- `assets/`：最终欢迎图与侧栏图标；与 HTML 保持同目录。
- 双击 `index.html` 即可查看，无需安装依赖。
- 新增演示对话「产线报警统计与图表切换」展示处理摘要和图表切换。

当前使用固定演示数据，未连接 Diviner，追问不真实重算；文件未上传解析，语义保存为模拟，收藏和历史未持久化，导出仅为示例文本。正式接入需验证权限、UNS/文件到语义模型的映射、会话上下文与语义写入接口。
