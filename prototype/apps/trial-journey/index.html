      没连上时，检查这里
      提示 401 / 认证失败
      检查 appKey 是否完整、已启用，是否属于当前平台；确认 Bearer 后保留空格。
      提示 403 / 权限不足
      连接已到达平台，但账号可能没有对应权限，请联系平台管理员确认。
      超时 / 地址不存在
      检查平台域名和端口、网络或 VPN，以及 MCP 服务是否已开放。
      没有调用 supOS 工具
      确认连接器已启用，并在当前对话中选中；必要时保存配置后新建对话再试。
